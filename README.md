# Limon Chacchu Caption Ghor — নতুন সাইট (v1)

প্লেইন HTML + CSS + JS + Supabase + Netlify। কোনো build step নেই।

## GitHub Pages (যেমন limonchacchu.github.io/Caption/)
সব পাথ রিলেটিভ, তাই সাবফোল্ডারেও কাজ করে। zip-এর সব ফাইল রিপোজিটরির রুটে আপলোড করুন (পুরোনো ফাইল রিপ্লেস করে)।
Supabase → Authentication → URL Configuration-এ Site URL ও Redirect URL দিন: `https://limonchacchu.github.io/Caption/`
নোট: GitHub Pages-এ `netlify.toml`-এর হেডার ও `robots.txt` কাজ করে না (robots.txt ডোমেইনের রুটে থাকতে হয়)। অ্যাডমিন পেজে `noindex` মেটা ট্যাগ আছে, তবে অ্যাডমিনের আসল সুরক্ষা লগইন, রোল ও RLS।
পুরোনো সংস্করণ দেখালে: ব্রাউজারে Ctrl+Shift+R বা সাইট ডেটা মুছুন (service worker ক্যাশ)।

## GitHub → Netlify ডিপ্লয়
1. নতুন GitHub রিপোজিটরি বানিয়ে এই ফোল্ডারের সব ফাইল রুটে আপলোড করুন।
2. Netlify → Add new site → Import from GitHub → রিপোজিটরি বেছে নিন।
   Build command ফাঁকা রাখুন, Publish directory `/` (বা ফাঁকা)।
3. ডিপ্লয় হলেই সাইট চালু হবে। Supabase ছাড়াও নমুনা কনটেন্ট দিয়ে কাজ করে।

## Supabase চালু করা (লগইন, পছন্দ, রিয়েল কনটেন্ট)
1. supabase.com-এ ফ্রি প্রজেক্ট খুলুন।
2. SQL Editor-এ ক্রমানুসারে চালান: `supabase/001_profiles.sql`, তারপর `supabase/002_content.sql`।
3. Project Settings → API থেকে URL ও **anon/publishable** key নিয়ে `assets/js/config.js`-এ বসান।
   **service_role key কখনো এখানে বসাবেন না।**
4. Authentication → URL Configuration-এ আপনার Netlify URL দিন। Google লগইনের জন্য Providers-এ Google চালু করুন।
5. নিজেকে অ্যাডমিন বানাতে `002_content.sql`-এর শেষের কমেন্টেড SQL চালান।
6. কনটেন্ট যোগ করতে এখন Supabase Table Editor-এ `contents` টেবিলে `status = published` দিয়ে সারি যোগ করুন (Admin Panel পরের ধাপে)।

## সোশ্যাল লিংক
`config.js`-এর `SOCIAL`-এ শুধু আপনার আসল https লিংক দিন। ফাঁকা থাকলে দেখাবে না।

## Design Studio (`/design.html`)
১১টি রেডি টেমপ্লেট, একাধিক লেখা (টেনে সরানো/বড়-ছোট/ঘোরানো), ৭টি বাংলা ওপেন-লাইসেন্স ফন্ট, গ্র্যাডিয়েন্ট/একরঙা/নিজের ছবি ব্যাকগ্রাউন্ড, আনডু/রিডু, ১:১, ৪:৫, ৯:১৬, ১৬:৯ ও কাস্টম সাইজ, PNG/JPG (হাই-রেজ), প্রিভিউ, ফাইলের নাম, ওয়াটারমার্ক সুইচ, সেভ (এই ডিভাইসে; লগইন করলে অ্যাকাউন্টে)।
অ্যাকাউন্টে সেভের জন্য `supabase/003_designs.sql` চালান। হোমপেজের কার্ডে 🎨 বাটন ক্যাপশন সরাসরি স্টুডিওতে পাঠায়।

## Admin Panel (`/admin.html`)
লগইন + MFA (TOTP), রোল চেক (admin/moderator), ওভারভিউ (বাস্তব সংখ্যা), কনটেন্ট CRUD + ফিল্টার + বাল্ক অ্যাকশন (মুছতে নিশ্চিতকরণ), সাবমিশন অনুমোদন/বাতিল + ফিডব্যাক, ইউজার রোল/সাসপেন্ড (শুধু admin), সোশ্যাল লিংক ম্যানেজার (https যাচাই), ওয়াটারমার্ক সেটিং, JSON/CSV এক্সপোর্ট, অডিট লগ।
**সেটআপ:** `supabase/004_admin.sql` চালান, তারপর নিজেকে admin বানান (ফাইলের শেষের SQL)। MFA চালু করে লগইন নিশ্চিত হলে ঐচ্ছিক `004b_require_mfa.sql` চালান, এতে ডেটাবেজ নিজেই MFA ছাড়া অ্যাডমিন ক্ষমতা দেবে না। আগে MFA না করে 004b চালালে নিজেই লক হয়ে যাবেন।
নিরাপত্তা আসে RLS থেকে, বাটন লুকানো থেকে নয়। মডারেটর মুছতে পারে না, রোল বদলাতে পারে না।

## Admin Panel (`/admin.html`)
লগইন + MFA (TOTP), রোল-ভিত্তিক মেনু (অ্যাডমিন/মডারেটর), ওভারভিউ (বাস্তব সংখ্যা), কনটেন্ট CRUD ও বাল্ক অ্যাকশন (মোছার আগে কনফার্মেশন, শুধু অ্যাডমিন মুছতে পারে), সাবমিশন রিভিউ (ফিডব্যাকসহ), ইউজার রোল ও সাসপেন্ড, সোশ্যাল লিংক ম্যানেজার (শুধু বৈধ https), ওয়াটারমার্ক সেটিং, JSON/CSV এক্সপোর্ট, অডিট লগ (ডাটাবেজ ট্রিগার দিয়ে লেখা, ক্লায়েন্ট থেকে বদলানো যায় না)।
**সেটআপ:** `supabase/004_admin.sql` চালান, তারপর নিজেকে অ্যাডমিন বানান (ফাইলের শেষের SQL)। অ্যাডমিন → সেটিংস থেকে MFA চালু করে লগইন যাচাই করার **পরে** চাইলে `004b_require_mfa.sql` চালান। তখন ডাটাবেজ নিজেই MFA ছাড়া অ্যাডমিন ক্ষমতা দেবে। আগে চালালে নিজেই লক হয়ে যেতে পারেন।
